# Professional Designer & Developer Portfolio

A sleek, dark-themed, modern personal portfolio website designed to showcase professional experience, skills, projects, and services. Built with a responsive layout, custom UI components, smooth navigation, and a integrated contact system.

---

## 🚀 Overview & Features

| Section | Description | Key Components |
| :--- | :--- | :--- |
| **Hero / Intro** | Introduction banner with profile highlight and call-to-action buttons. | Profile Image, Stats Counters, CTA Buttons |
| **About Me** | Personal background, experience highlights, and key milestones. | Experience Cards, Bio Text, Quick Info |
| **Skills & Expertise** | Visual presentation of technical and design proficiencies. | Animated Skill Progress Bars, Tech Stack Icons |
| **Resume & Timeline** | Detailed history of work experience and educational background. | Timeline Cards, Role Descriptions, Date Badges |
| **Services** | Overview of services provided to clients. | Service Cards, Icon Highlights, Learn More Links |
| **Portfolio Showcase** | Interactive gallery of past projects, designs, and case studies. | Categorized Filter Tabs, Project Preview Grid |
| **Client Reviews** | Social proof, ratings, and testimonials from past clients. | Testimonial Cards, Star Ratings (4.8/5.0) |
| **FAQ** | Frequently Asked Questions section to address common inquiries. | Accordion Dropdown List |
| **Contact** | Direct communication form and contact details. | Interactive Form, Direct Links, Social Media Icons |

## ⚡ Quick Start & Installation

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/lucky-kumar196/portfolio/
   cd portfolio
   ```

2. **Open Locally:**
   Simply open `index.html` in any modern web browser or serve it using Live Server:
   ```bash
   npx live-server
   ```
